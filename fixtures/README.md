# Regression fixtures

These are small, deterministic inputs used by the CLI tests and cold-agent sandbox:

- `donuts-cake.svg`: single-asset and metadata scenarios
- `series/`: multi-token image and trait scenarios
- `p5-dep-proof/`: code-project and on-chain dependency scenarios
- `code-drop-rehearsal/`: resumable code-deployment tests

They are test fixtures, not a gallery or a second tutorial set. User-facing examples belong in the
maintained docs site. The JavaScript and HTML fixtures are part of ABX and use the repository's MIT
license.
