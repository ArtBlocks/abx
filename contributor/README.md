# Contributor test tooling

This directory holds development-only material that validates the experience shipped to end users:

- [`distribution-testing.md`](distribution-testing.md) explains the clean-room and packaged-artifact
  test tiers.
- [`agent-eval/`](agent-eval/) contains cold-agent scenarios, rubrics, and the feedback template used
  by the clean-room harness.

These are executable regression assets, not product strategy or a work-tracking system. Public user
and protocol documentation belongs in `site/content/docs/`; future work belongs in GitHub Issues.
