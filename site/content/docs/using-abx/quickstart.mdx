## Before you start

- Node.js 22.13 or newer
- A coding agent with shell access
- An email address for gas sponsorship, or your own wallet and testnet gas

This guide uses the default testnet. ABX is adding more EVM networks. Check
[Networks and deployments](/docs/reference/deployments) for the current list before choosing one.

When sponsorship is available, you do not need a private key or faucet funds. You can also use a
browser wallet, an environment key, or unsigned transactions.
