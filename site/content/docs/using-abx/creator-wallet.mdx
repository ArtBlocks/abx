---
title: "Creator wallet"
description: "Deploy on eligible Base networks without bringing a funded wallet."
---

ABX Services can give a verified account one embedded creator wallet. The wallet address stays tied
to the account's email and API key; the API key cannot sign.

This is a beta on **Base Sepolia** and, when the live service explicitly advertises it, **Base
mainnet**. Sponsorship is policy-limited and may be paused. When it is available, it is the
recommended path for a first testnet launch: no private key, funded wallet, or faucet visit is
required. Bring-your-own wallet flows remain available everywhere.

```bash
abx auth login
abx remote abx
abx deploy ... --dry-run --json
abx deploy ... --sponsor
```

The real send opens Privy once. Match the code, review the transaction group, and authorize the
agent. The CLI keeps that grant only in memory, signs each exact request, and discards it when the
command ends. ABX Services adds its provider credential and relays only eligible transactions.

Current limits:

- Base Sepolia (`84532`), plus Base (`8453`) only when both the live provider and your account
  advertise it;
- zero ETH value;
- gas must be accepted by the network and live sponsorship provider; ABX adds no lower gas ceiling.

Factory deployments, direct `abx deploy-contract` creation, and staged `--onchain-image` transaction
groups use the same lane. Each group is serialized under one short-lived authorization; a later
transaction is not prepared until the receipt it depends on is confirmed.

An ambiguous submission is never retried. Keep the operation ID from the error and check its status
before taking another action.

The live remote and account response determine whether sponsorship is enabled. ABX sponsorship is a
convenience, not part of the protocol. You can always use `--send`, `--sign`, or `--unsigned`
instead. Before a sponsored Base mainnet operation, prove the exact flow on Base Sepolia, review the
production-network warning and permanent choices, and confirm that both the live descriptor and
your account advertise chain `8453`.
