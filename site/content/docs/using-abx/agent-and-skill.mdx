The CLI works by itself. The skill teaches a coding agent how to choose commands, explain permanent
settings, and stop for wallet approvals.

## Install the matching skill

```bash
abx skill install
```

The skill version is stamped when the CLI ships. `abx doctor` warns when the installed copy no longer
matches. Run the install command again after each CLI upgrade.

The default install covers Claude Code, Cursor, Codex CLI, Gemini CLI, and GitHub Copilot. To limit the
install, use one of these:

```bash
abx skill install --agent codex
abx skill install --agent cursor
abx skill install --global
```

Restart the agent after installation.

## Choose the signer deliberately

On a supported network, the agent checks the live ABX Services descriptor before asking you to set
up a wallet. If sponsorship is advertised and the transaction group is eligible, it recommends
`--sponsor`—especially on testnet. Your account-bound creator wallet signs through a short-lived
authorization, and the service pays the eligible gas.

You can always bring your own signer instead: `--sign` opens a browser wallet, `--send` uses an
environment key for deliberate automation, and `--unsigned` prepares transactions for a multisig or
offline signer. The agent honors an explicit choice and reruns the dry run if the signer changes.
See [signing modes](/docs/reference/cli#signing-lanes).

## What the skill does not do

The skill does not choose your edition size, storage permanence, royalty terms, or sale price. It
should ask, show the resulting plan, and wait for your approval.
