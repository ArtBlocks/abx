Install the CLI globally or run it through `npx`:

```bash
npm install --global @artblocks/abx-cli
abx help
```

Use `abx <command> --help` for every flag and example. This page is a map, not a second copy of the
built-in help.

## Start and inspect

| Command | Use |
| --- | --- |
| `demo` | Deploy, index, and serve a test 1/1 |
| `doctor` | Check Node, RPC, factories, storage, skill version, and optional signing setup |
| `capabilities` | Print supported project types and irreversible choices |
| `state` | Read owner-controlled settings and parameter schemas |
| `verify` | Check canonical deployment, byte commitments, and render freshness |
| `tokenuri` / `contracturi` | Read committed metadata; `contracturi` follows its URI and `--json` is machine-readable |
| `tokens` | List token state from the contract |
| `artifacts` | List served artifacts and current or stale effect output |
| `status` | Show resolver indexing state |
| `version` / `help` | Show the installed version or command help |

## Signing lanes

Every write uses one lane:

| Flag | Behavior |
| --- | --- |
| `--sponsor` | Use an eligible account-bound creator wallet and provider-paid gas |
| `--sign` | Open a browser wallet |
| `--send` | Sign with the configured hot key |
| `--unsigned` | Print an unsigned transaction |
| `--dry-run` | Simulate without sending |

If the creator has not chosen a signer, use the live remote descriptor to prefer sponsorship when the
chain and transaction group are eligible. Otherwise choose the appropriate bring-your-own lane.
Never paste a private key into a chat or prompt.

A deploy preview reports the wallet approvals it will need. A predicted address is stable only when you
reuse the displayed salt with `--salt`. A salt's first 20 bytes are its deployer guard: they must be
zero (permissionless) or the address that will sign. The CLI refuses a known signer/guard mismatch
before authorization or broadcast.

### Structured deploy plan (`--dry-run --json`)

`deploy`, `deploy-series`, and `deploy-code` include a versioned `plan` object in JSON output. It
contains the signing lane, transaction groups, roles, royalties, custody, mint plan, estimates,
warnings, required public surfaces, dependencies, and resume state. Unknown values are `null`.

`transactions.approvals` is the number of wallet approvals. `transactions.legs` names the logical
groups they contain. Large code deployments may split setup across transactions. `deploy-code
--resume` continues the idempotent setup steps, and reserve mints run last.

## Agent skill and updates

`abx skill install` installs the version-matched agent skill. `abx doctor` reports drift between the
skill and CLI.

The CLI may print a notice when a newer npm release exists. It never upgrades itself. Set
`ABX_NO_UPDATE_CHECK=1` to disable the check.
